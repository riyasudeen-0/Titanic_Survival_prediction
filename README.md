# Titanic Survival Prediction

An end-to-end Machine Learning project to predict
passenger survival aboard the Titanic using Python
and Scikit-learn.

## Objective

Build a classification model to predict whether
a passenger survived the Titanic disaster.

## Dataset

Kaggle - Titanic: Machine Learning from Disaster

Dataset files should be downloaded from Kaggle
and placed inside the `data/` directory.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
